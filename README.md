## 📝 About The Project

The **Diabetes Comprehensive Guide** is a responsive web application tailored for Arabic-speaking users. It serves as a digital health companion, offering vital information on diabetes management, a structured daily diet plan, and a built-in medical calculator. The application is built as a **Progressive Web App (PWA)**, allowing users to install it directly on their mobile devices and use it seamlessly.

### 🚀 Key Features

*   **🧮 Built-in BMI Calculator:** Calculates Body Mass Index and provides instant, color-coded health feedback related to diabetes risks.
*   **🥗 Interactive Diet Plan:** A structured daily meal plan (Breakfast, Snacks, Lunch, Dinner) utilizing a clean accordion interface.
*   **🛡️ Prevention Guidelines:** Quick-access modals providing actionable tips for preventing Type 2 Diabetes.
*   **📱 PWA Ready:** Includes a `manifest.json` and a Service Worker (`sw.js`) for mobile installation and offline caching capabilities.
*   **🔗 Native Sharing:** Integrates the Web Share API for easy content sharing across mobile devices.
*   **🌐 SEO & Social Media Optimized:** Fully configured with Open Graph and Twitter Cards meta tags for professional link previews.
*   **🌍 RTL Support:** Native Right-to-Left design optimized for Arabic typography and UI/UX.

---

## 🛠️ Built With

This project was built entirely with modern front-end web technologies, requiring no complex build tools or backend dependencies:

*   **HTML5 & CSS3**
*   **[Bootstrap 5 (RTL)](https://getbootstrap.com/)** - For responsive design and UI components (Modals, Accordions, Cards).
*   **Vanilla JavaScript (ES6+)** - For the BMI logic, PWA installation, and Share API.
*   **Bootstrap Icons** - For high-quality vector icons.
*   **Service Workers** - For PWA offline capabilities.
